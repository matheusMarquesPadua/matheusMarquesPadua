# Olá, eu sou o Matheus Padua! 👋

Sou um desenvolvedor de software especializado em **Backend**, com foco no ecossistema C# e .NET. Gosto de criar APIs robustas e escaláveis aplicando padrões de Clean Architecture (Arquitetura Limpa) e boas práticas de engenharia.

### 💻 Sobre mim
- 🔭 Atualmente desenvolvendo o **Tasks-Backend**, uma API de gerenciamento de tarefas usando .NET 10, Entity Framework Core, PostgreSQL, CQRS e pipeline do MediatR com FluentValidation.
- 🎓 Colaborando em projetos de software e extensão acadêmica no **UniCV** (como o *Nossa Feirinha* e o *Radar do Conhecimento*).
- 🌱 Dedico parte do meu dia para aprimorar meu inglês técnico voltado para programação.
- 🥋 Quando não estou codando, você pode me encontrar no tatame treinando Jiu-Jitsu ou jogando no PC.
